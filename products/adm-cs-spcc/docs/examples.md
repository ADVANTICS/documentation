# Examples of use

## Simplified CCS/MCS charger

A basic wiring for CCS/MCS charger, with one CCS/MCS pistol. Only the essential components shown – the full implementation can also contain temperature control, LCD screen connected over Ethernet, ground fault monitor (if not included in the power modules), RFID reader and similar.
